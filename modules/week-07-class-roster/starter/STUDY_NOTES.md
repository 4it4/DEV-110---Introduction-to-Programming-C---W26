## Arrays and `count`

**What are “parallel arrays” and how did you use them in this assignment?**
[Explain how rosterNames and rosterCredits stay lined up by index]

Answer: Parallel arrays are two or more arrays that store similar data within the same index. rosterNames and rosterCredits are parallel arrays and they stay lined up because they are in the same index.

**What is the purpose of the `count` variable?**
[Explain how it tracks how many roster slots are “in use”]

Answer: stores how many roster slots are in use. it relays how many of the students have been added.

**Where did you use `count` in loops and why?**
[Explain why you loop 0..count-1 instead of using the full array length]

Answer: I looped from 0 to count 1 because those positions have student data. The full array length would have leftovers.
